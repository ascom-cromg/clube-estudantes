# Clube dos Estudantes de Odontologia de Minas Gerais

Portal web do Clube dos Estudantes, com foco na campanha **Complete seu cadastro**.

## Áreas

- Login
- Início
- Meu Perfil
- Painel Administrativo
- Importação de planilha XLSX/XLS/CSV
- Exportação da base em CSV
- Segmentação de cadastros incompletos

## Publicação

O repositório está configurado para publicar automaticamente no GitHub Pages a cada atualização da branch `main`.

Endereço esperado:

`https://ascom-cromg.github.io/clube-estudantes/`

## Observação

A versão atual é um protótipo funcional front-end. Os dados demonstrativos ficam no `localStorage` do navegador. Para uso real com múltiplos usuários, será necessário conectar autenticação e banco de dados/API.
